## What We Are Comparing

| | Kiro | Amazon Bedrock (Claude) |
|---|---|---|
| **Interface** | IDE-native (VS Code extension) | API / AWS Console / third-party clients |
| **Model** | Claude (via Kiro) | Claude (via Bedrock) |
| **Context** | Workspace-aware — reads your files, git, terminal | Stateless by default — you provide context manually |
| **Actions** | Can edit files, run commands, create hooks | Returns text only — your app handles actions |
| **Setup** | Install Kiro extension | AWS account + Bedrock access + API integration |
